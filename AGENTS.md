## Project Overview

**StudyMate** — образовательная веб-платформа для самостоятельного обучения с использованием LLM.

Основные возможности:
- Регистрация и авторизация пользователей.
- Загрузка учебных материалов (PDF, DOCX, PPTX).
- Извлечение текста из документов.
- Генерация тестов и открытых вопросов на основе материалов.
- Прохождение тестирования.
- Проверка открытых ответов с помощью LLM.
- Просмотр результатов и прогресса обучения.

**Основная задача:** помогать пользователям эффективнее изучать учебные материалы и проверять свои знания.

## Architecture

Проект разделён на две независимые части:

### Backend (`backend/`)

- `app/api/` — API endpoints и роутеры.
- `app/core/` — конфигурация и общие настройки.
- `app/models/` — модели базы данных.
- `app/schemas/` — Pydantic-схемы запросов и ответов.
- `app/services/` — бизнес-логика.
- `app/main.py` — точка входа приложения.

**Правила:**
- Роутеры отвечают за обработку HTTP-запросов и вызывают сервисы.
- Бизнес-логика находится в `services/`.
- Парсинг PDF, DOCX и PPTX выполняется средствами Python.
- Взаимодействие с GigaChat API вынесено в отдельный сервис.
- API-ключи и секреты хранятся только на backend.

### Frontend (`frontend/`)

- `src/app/` — страницы и маршрутизация.
- `src/components/` — переиспользуемые UI-компоненты.
- `src/lib/` — вспомогательные функции и API-клиент.
- `src/hooks/` — пользовательские хуки.

**Правила:**
- Компоненты отвечают преимущественно за отображение интерфейса.
- Запросы к backend выносятся в отдельный API-клиент.
- Используй TypeScript и типизируй данные.
- Для UI используй shadcn/ui и Tailwind CSS.
- Не дублируй существующие компоненты и логику.

## Development Rules

- Соблюдай принципы KISS и DRY.
- Предпочитай простые и понятные решения.
- Не создавай лишние абстракции и файлы без необходимости.
- Используй type hints в Python.
- Следи за корректной обработкой ошибок.
- Не оставляй API-ключи и пароли в исходном коде.
- Не передавай секреты GigaChat во frontend.
- Не изменяй существующую функциональность без необходимости.
- Перед добавлением зависимостей проверяй, можно ли обойтись уже установленными библиотеками.
- После изменений проверяй работоспособность затронутого функционала.

## AI Integration

- Для всех AI-функций используй GigaChat API.
- Промпты должны находиться отдельно от основной бизнес-логики.
- По возможности используй структурированный JSON-ответ от модели.
- Проверяй и валидируй ответы LLM перед использованием.
- Не доверяй автоматически сгенерированным вопросам и оценкам без проверки формата и структуры.
- При проверке открытых ответов учитывай смысл ответа, а не только совпадение формулировок.
- При генерации вопросов используй исключительно содержание загруженных учебных материалов.
