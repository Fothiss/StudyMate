# StudyMate

**StudyMate** — интеллектуальная образовательная платформа для самостоятельного обучения с использованием больших языковых моделей (LLM).

Приложение позволяет загружать учебные материалы, автоматически генерировать по ним тесты и открытые вопросы, а также проверять ответы с помощью искусственного интеллекта.

## Цель проекта

Упростить процесс самостоятельной подготовки к экзаменам и изучения новых материалов. StudyMate помогает превратить обычные лекции и презентации в интерактивные задания, оценить уровень усвоения информации и выявить темы, требующие дополнительного изучения.

## Основной функционал

- **Регистрация и авторизация** — создание пользовательского аккаунта.
- **Загрузка материалов** — загрузка лекций, конспектов и презентаций в форматах PDF, DOCX и PPTX.
- **Обработка документов** — извлечение и подготовка текста из загруженных материалов.
- **Генерация заданий** — автоматическое создание вопросов на основе учебных материалов с возможностью выбора типа и сложности.
- **Прохождение тестов** — ответы на вопросы с вариантами ответов и открытые вопросы.
- **Проверка ответов** — автоматическая оценка открытых ответов с помощью LLM, объяснение ошибок и предоставление обратной связи.
- **Статистика обучения** — просмотр результатов тестирования и отслеживание прогресса.

## Архитектура проекта

Проект разделён на две основные части:

- **Frontend** — пользовательский интерфейс, взаимодействие с пользователем и отображение результатов.
- **Backend** — обработка запросов, работа с базой данных, обработка документов и взаимодействие с GigaChat API.

Взаимодействие между frontend и backend осуществляется через REST API.

## Основной сценарий использования

1. Пользователь регистрируется или входит в систему.
2. Загружает учебный материал.
3. StudyMate извлекает текст из документа.
4. Пользователь выбирает параметры генерации заданий.
5. GigaChat API генерирует вопросы на основе загруженного материала.
6. Пользователь проходит тестирование.
7. Система проверяет ответы и формирует результаты.
8. Пользователь изучает ошибки и отслеживает свой прогресс.

## Запуск проекта

Инструкции по установке зависимостей, настройке переменных окружения и запуску frontend и backend будут добавлены в процессе разработки.

Для работы AI-функциональности необходимо получить доступ к GigaChat API и настроить соответствующие учётные данные в переменных окружения backend.
