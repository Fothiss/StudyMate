# StudyMate

**StudyMate** — интеллектуальная образовательная платформа для самостоятельного обучения с использованием больших языковых моделей (LLM).

Приложение позволяет загружать учебные материалы, автоматически генерировать по ним тесты и открытые вопросы, а также проверять ответы с помощью искусственного интеллекта.

## Цель проекта

Упростить процесс самостоятельной подготовки к экзаменам и изучения новых материалов. StudyMate помогает превратить обычные лекции и презентации в интерактивные задания, оценить уровень усвоения информации и выявить темы, требующие дополнительного изучения.

## Основной функционал

- **Регистрация и авторизация** — создание пользовательского аккаунта.
- **Загрузка материалов** — загрузка лекций, конспектов и презентаций в форматах PDF, DOCX и PPTX.
- **Обработка документов** — извлечение и подготовка текста из загруженных материалов.
- **Генерация заданий** — автоматическое создание вопросов на основе учебных материалов с возможностью выбора типа и сложности.
- **Прохождение тестов** — ответы на вопросы с вариантами ответов и открытые вопросы.
- **Проверка ответов** — автоматическая оценка открытых ответов с помощью LLM, объяснение ошибок и предоставление обратной связи.
- **Статистика обучения** — просмотр результатов тестирования и отслеживание прогресса.

## Архитектура проекта

Проект разделён на две основные части:

- **Frontend** — пользовательский интерфейс, взаимодействие с пользователем и отображение результатов.
- **Backend** — обработка запросов, работа с базой данных, обработка документов и взаимодействие с GigaChat API.

Взаимодействие между frontend и backend осуществляется через REST API.

## Основной сценарий использования

1. Пользователь регистрируется или входит в систему.
2. Загружает учебный материал.
3. StudyMate извлекает текст из документа.
4. Пользователь выбирает параметры генерации заданий.
5. GigaChat API генерирует вопросы на основе загруженного материала.
6. Пользователь проходит тестирование.
7. Система проверяет ответы и формирует результаты.
8. Пользователь изучает ошибки и отслеживает свой прогресс.

## Запуск проекта

### Backend

Требуется Python 3.12+ и [uv](https://docs.astral.sh/uv/). Пакеты ставятся только через `uv`, pip не используется.

```bash
cd backend
uv sync                                                              # зависимости и виртуальное окружение
uv run python -c "import secrets; print(secrets.token_urlsafe(48))"   # сгенерировать SECRET_KEY
copy .env.example .env                                               # затем вписать полученный SECRET_KEY
uv run python -m app.main                                            # сервер на 127.0.0.1:8000
```

Порт, хост и автоперезапуск берутся из `HOST`, `PORT` и `RELOAD` в `.env`. Эквивалентный запуск вручную — `uv run uvicorn app.main:app --reload`.

После старта:

- `http://127.0.0.1:8000/docs` — Swagger UI; кнопка **Authorize** принимает токен, полученный в `/auth/login`.
- `http://127.0.0.1:8000/health` — проверка работоспособности.
- база данных создаётся автоматически в `backend/studymate.db`, файлы материалов — в `backend/storage/`.

Схема БД создаётся при старте приложения и не мигрируется: `create_all` не изменяет существующие таблицы. После изменения моделей удалите `backend/studymate.db`, и она соберётся заново.

### Frontend

React, Vite, TypeScript, Tailwind CSS и shadcn/ui. Пакеты ставятся через `npm`. Backend должен быть уже запущен — frontend обращается к нему по `VITE_API_URL`.

```bash
cd frontend
npm install                                     # зависимости
copy .env.example .env.local                    # адрес backend, по умолчанию 127.0.0.1:8000
npm run dev                                     # http://localhost:3000
```

Сборка — статические файлы в `frontend/dist`, Node-сервер для раздачи не нужен:

```bash
npm run build                                   # проверка типов и сборка в dist/
npm run preview                                 # локальный просмотр собранного dist/
```

`npm run lint` проверяет исходники ESLint.

Страницы:

- `/` — обзор: свои материалы, загрузка PDF, переход к тесту и раздел «Результаты» (пока недоступен);
- `/quiz` — тренажёр: выбор материала, количество тестовых и открытых вопросов, прохождение без показа ответов, результат с разбором и оценкой открытых ответов через GigaChat;
- `/login` — вход;
- `/register` — регистрация с автоматическим входом.

Тема переключается в оболочке приложения (тёмная и светлая). Без сохранённого токена
приватные страницы перенаправляют на `/login`; выход очищает токен на клиенте.
Сгенерированный тест, ответы и результат живут в `sessionStorage` вкладки — на сервере
они не сохраняются.
