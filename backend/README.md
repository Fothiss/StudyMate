# StudyMate backend

Backend образовательной платформы StudyMate: FastAPI, SQLAlchemy, SQLite.

## Запуск

```bash
uv sync
uv run python -m app.main          # 127.0.0.1:8000, автодокументация на /docs
```

## Эндпоинты

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/health` | проверка работоспособности |
| `POST` | `/auth/register` | регистрация (`username`, `password`) |
| `POST` | `/auth/login` | вход, отдаёт `access_token` (форма `username`/`password`) |
| `GET` | `/users/me` | профиль текущего пользователя |
| `POST` | `/materials` | загрузка PDF (`title` + `file`) |
| `GET` | `/materials` | материалы текущего пользователя |
| `GET` | `/materials/{id}` | один материал |
| `POST` | `/materials/{id}/quiz` | генерация теста по тексту материала |
| `POST` | `/quiz/check` | проверка открытых ответов через GigaChat |

Все эндпоинты кроме `/health`, `/auth/register` и `/auth/login` требуют заголовок
`Authorization: Bearer <token>`.

## Генерация теста

`POST /materials/{id}/quiz` принимает состав теста в теле запроса:

```json
{ "choice_count": 5, "open_count": 2 }
```

- `choice_count` — сколько тестовых вопросов с вариантами ответов, `0..15`;
- `open_count` — сколько открытых вопросов с эталонным ответом, `0..10`;
- сумма обязана быть больше нуля, иначе `422`.

Поля можно опустить: по умолчанию `{"choice_count": 5, "open_count": 0}`.

Ответ — краткое содержание и вопросы двух типов:

```json
{
  "summary": ["Пункт 1", "Пункт 2", "Пункт 3"],
  "questions": [
    {
      "kind": "choice",
      "text": "Вопрос с вариантами",
      "options": ["A", "B", "C", "D"],
      "correct_index": 2
    },
    {
      "kind": "open",
      "text": "Открытый вопрос",
      "reference": "Эталонный ответ"
    }
  ]
}
```

Тест не сохраняется: каждый запрос генерирует новый.

```bash
curl -X POST "$BASE/materials/$ID/quiz" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"choice_count": 4, "open_count": 0}'
```

Коды: `200` — тест получен, `401` — нет токена, `404` — материала нет или он чужой,
`422` — нет извлечённого текста или некорректный состав, `502` — модель недоступна
или вернула непригодную структуру.

## Проверка открытых ответов

`POST /quiz/check` принимает ответы студента на открытые вопросы теста — все сразу,
одним запросом:

```json
{
  "material_id": "e0f1...",
  "answers": [
    {
      "question": "Что поглощает свет в хлоропластах?",
      "reference": "Хлорофилл",
      "answer": "Хлорофилл — пигмент, который поглощает свет"
    }
  ]
}
```

`reference` присылает клиент: тест транзитивный, сервер его не хранит. Пустой ответ
в модель не отправляется — он сразу получает нулевой балл с пояснением.

Ответ — по одной оценке на каждый отправленный ответ, в том же порядке:

```json
{
  "results": [
    { "index": 0, "score": 90, "feedback": "Верно, можно добавить роль хлорофилла" }
  ]
}
```

`score` — целое от `0` до `100`. Проверка не сохраняется: каждый запрос оценивает заново.

```bash
curl -X POST "$BASE/quiz/check" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d "@answers.json"
```

Коды: `200` — ответы проверены, `401` — нет токена, `404` — материала нет или он чужой,
`422` — нет извлечённого текста, `502` — модель недоступна или вернула непригодный ответ.
