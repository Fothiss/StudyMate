# Proposal

## Why

Фронтенд работает, но остаётся стоковой заготовкой shadcn: neutral-палитра, три экрана, ни одной анимации, ни одной иконки. При этом главный сценарий продукта не пройден до конца: тест по материалу показывается с уже подсвеченным правильным ответом, поэтому «проверить себя» невозможно — это просмотр, а не тренажёр. Выбрать количество вопросов и их тип тоже нельзя: пять вопросов с четырьмя вариантами зашиты в промпт.

Вторая проблема — стек. Приложение целиком клиентское (токен в `localStorage`, во всех страницах `"use client"`), но держится на Next.js с двумя экспериментальными флагами и требует Node-сервер для раздачи статики. Мы всё равно переписываем интерфейс, поэтому дешевле снять эту зависимость сейчас, чем тащить её в новый дизайн.

Change закрывает первый осмысленный цикл обучения: **загрузил материал → настроил тест → прошёл его → получил разбор**.

## What Changes

- **BREAKING**: фронтенд переезжает с Next.js 16 на Vite + React Router. Маршруты `/`, `/login`, `/register` сохраняются, добавляется `/quiz`. `next/font` заменяется self-hosted шрифтами, `cacheComponents`/`partialPrefetching` и dev-индикатор исчезают вместе с Next.
- Новая дизайн-система «Aurora»: тёмная и светлая темы через CSS-переменные с переключателем, бренд-градиент violet→fuchsia→cyan, стеклянные поверхности для навигации и статусов, непрозрачные карточки под текстом, иконки `lucide-react`, четыре места анимаций с уважением к `prefers-reduced-motion`.
- Общая оболочка приложения: компактный сайдбар с иконками и градиентным логотипом вместо текущей тонкой полоски.
- Новая страница `/quiz` — визард из трёх шагов: выбор материала → параметры генерации → прохождение. Правильные ответы не показываются до завершения.
- `POST /materials/{id}/quiz` получает тело `{choice_count, open_count}` вместо жёстко заданных пяти вопросов.
- Схема вопроса становится объединением: тестовый (`kind=choice`, варианты + индекс) или открытый (`kind=open`, эталонный ответ).
- Новый эндпоинт `POST /quiz/check`: GigaChat оценивает открытые ответы студента и возвращает балл и разбор. Один запрос на все открытые ответы.
- Результат прохождения — круговой счёт, разбор по каждому вопросу и карточки обратной связи от модели. Хранится только в `sessionStorage` браузера.
- Дашборд перестаёт генерировать тесты внутри карточки: остаются приветствие, сводка материалов, загрузка PDF и переход на `/quiz`.
- `AGENTS.md` и `README.md` фиксируют Vite вместо Next.js.

## Capabilities

### New Capabilities

- `web-quiz`: страница настройки и прохождения теста — параметры генерации, пошаговое прохождение без показа правильных ответов, проверка тестовых ответов на клиенте, запрос оценки открытых ответов, экран результата с разбором и восстановление состояния после перезагрузки вкладки.

### Modified Capabilities

- `web-dashboard`: генерация теста на дашборде заменяется переходом на отдельную страницу `/quiz`; добавляется общая навигационная оболочка; сводка материалов и загрузка PDF сохраняются.
- `material-quiz`: генерация принимает запрошенное количество вопросов каждого типа; структура вопроса расширяется тестовым и открытым вариантами; добавляется требование оценки открытых ответов языковой моделью.

## Impact

- **Новый код (frontend)**: `vite.config.ts`, `index.html`, `src/main.tsx`, `src/app/router.tsx`, `src/app/layout/*`, `src/styles/aurora.css`, `src/components/quiz/*`, `src/lib/quiz-storage.ts`, `src/hooks/use-theme.ts`.
- **Удаляется**: `next.config.ts`, `src/app/layout.tsx`, `src/app/page.tsx`, `src/app/login/page.tsx`, `src/app/register/page.tsx` (переезжают в `src/pages/`), `src/components/quiz-block.tsx`, зависимости `next`, `@tailwindcss/turbopack`, `eslint-config-next`, `tw-animate-css` (если не нужен).
- **Изменяемые файлы (frontend)**: `package.json`, `tsconfig.json`, `eslint.config.mjs`, `components.json`, `src/lib/api.ts`, `src/components/materials-block.tsx`, `src/components/header.tsx`.
- **Новый код (backend)**: `app/api/routes/quiz.py`, `app/schemas/quiz_check.py`, `app/services/prompts/quiz_check.py`.
- **Изменяемые файлы (backend)**: `app/schemas/quiz.py`, `app/services/prompts/quiz.py`, `app/services/gigachat.py`, `app/api/routes/materials.py`, `app/main.py`.
- **Новые эндпоинты**: `POST /quiz/check`.
- **Изменения API**: тело запроса у `POST /materials/{id}/quiz`; поле `kind` и эталонный ответ у вопроса в ответе генерации.
- **Новые зависимости**: frontend — `react-router`, `vite`, `@vitejs/plugin-react`, `@tailwindcss/vite`, `@fontsource-variable/manrope`, `@fontsource-variable/inter`; backend — нет. Библиотека анимаций не добавляется: эффекты покрываются CSS и View Transitions API.
- **Схема БД не меняется**: попытки и результаты не сохраняются, `material-quiz` остаётся транзитивной.
- **Вне scope**: роли и кабинет преподавателя, назначения тестов группам, сохранение попыток и раздел «Результаты», миграции Alembic, OCR сканированных PDF, загрузка `.docx`/`.pptx`, изменения авторизации.
